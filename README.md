# SQL Daily Learning

This repository documents my daily SQL learning journey. It contains my handwritten notes and the practice questions I solve in SQL Server using SSMS (SQL Server Management Studio).

## What's Inside

- **Handwritten notes:** theory notes from each day, uploaded as images
- **Practice queries:** SQL code I write and test in SSMS
- **Daily folders:** each day has its own folder (for example `SQL_Learning_Day_1`)

## Learning Resources

I am learning from the following sources:

- **Playlist:** SQL Ultimate Course by Data with Baraa (YouTube)
- **Articles:** GeeksforGeeks
- **Community posts:** Reddit and other SQL-related posts

## Practice Questions

Practice questions are taken from [LeetCode SQL 50](https://leetcode.com/studyplan/top-sql-50/). The solutions in this repository are my own attempts, written and tested in SSMS.

## Tools Used

- SQL Server
- SQL Server Management Studio (SSMS)
